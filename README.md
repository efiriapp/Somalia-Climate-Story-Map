# Somalia-Climate-Story-Map

Public climate story map for Somalia, built for the Institute of Climate and Environment (ICE) at SIMAD University.

v1 is a free, open-source React + TypeScript catalog: SIMAD logo left, ICE logo right, filters in between, and a hybrid map + list of ICE Stories and Global Stage moments.
