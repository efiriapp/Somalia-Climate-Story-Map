# Somalia-Climate-Story-Map

Public climate story map for Somalia, built for the Institute of Climate and Environment (ICE) at SIMAD University.

The interface follows a search-and-filter catalog (keyword search, advanced options, Apply) with ICE forest green branding, then a hybrid OpenStreetMap + story list.

## Run locally

```bash
npm install
npm run dev
```

Open the printed local URL. `npm test` runs catalog and brand tests. `npm run build` creates a static `dist/` folder.
